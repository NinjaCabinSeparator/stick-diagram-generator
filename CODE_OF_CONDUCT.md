**🧍 Stick Diagram Generator** is the complete English-language guide to a lightweight Windows tool that turns simple text prompts into clean stick-figure diagrams, poses, and stick-animation frames. Learn how to run the one-command setup, pick poses from a preset library, chain frames into motion, export to SVG or PNG, and drop diagrams into docs, slides, or code comments. Built for teachers, writers, and developers who need clear visuals without a design degree. **Completely free.** No signup. No paywall. No hidden chapters.

## 🛠 Feature Breakdown

### Feature 1 — Pose Library
Choose from 80+ preset stick-figure poses: standing, running, jumping, pointing, sitting, and more.

### Feature 2 — Frame Chain
Link multiple poses into a simple animation sequence with adjustable timing.

### Feature 3 — Text Prompts
Describe a pose in plain English — the generator picks the closest match.

### Feature 4 — SVG + PNG Export
Export crisp vector SVG or ready-to-use PNG at any resolution.

### Feature 5 — Style Controls
Adjust stroke width, color palette, and background transparency.

### Feature 6 — Embed Ready
Drop diagrams into Markdown, slides, code comments, or design tools.

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Command fails** | Reopen as Admin |
| **Pose not found** | Shorten the prompt |
| **Export blank** | Check background color |
| **SVG won't open** | Use a modern browser |
| **Frames stuck** | Reduce frame count |
| **Install hangs** | Restart PowerShell |
